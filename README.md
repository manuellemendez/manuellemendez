# Manuel Mendez

I’m a front-end engineer based in Calgary. I spent more than five years at Vizzn building production React and TypeScript software for construction operations, including equipment, dispatch, and reporting workflows.

[Portfolio](https://portfoliopagemanuel.netlify.app/) · [Résumé](https://portfoliopagemanuel.netlify.app/resume.html) · [LinkedIn](https://www.linkedin.com/in/manuel-mendez-379025190/)

## At Vizzn

- Led a routing migration and the transition from Ant Design to shadcn/ui.
- Moved search and pagination to the server for equipment and dispatch workflows, reducing how much data the browser had to load.
- Built real-time messaging with threads and mentions, and shipped English, Spanish, and French support across reports and list views.
