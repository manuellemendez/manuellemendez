# Manuel Mendez

I’m a front-end engineer in Calgary. I spent more than five years at Vizzn building React and TypeScript software for construction teams, with a focus on equipment management, dispatch, and real-time messaging.

I’m also building [**Localword (Mira Ve)**](https://localwordapp.com/en#app), a restaurant discovery app for Cali, Colombia. The public demo shows how to find restaurants by dish and explore them on a map.
